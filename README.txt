RX-78-2 WHITE BASE - Codex Windows Gundam Skin
================================================

INSTALL
1. Install the Windows Codex app and launch it at least once.
2. Extract this entire ZIP. Do not run INSTALL.cmd inside a ZIP preview.
3. Double-click INSTALL.cmd.
4. Wait for Codex to restart and for the installer to report success.

After installation, this extracted folder can be deleted. Runtime files are
copied to:
%LOCALAPPDATA%\CodexDreamSkinGundam

UNINSTALL
- Double-click UNINSTALL.cmd from this package; or
- Run Uninstall-Skin.ps1 from the installed runtime folder.

FEATURES
- Runtime injection for Windows Codex; official app files are not modified.
- The debugging endpoint binds to 127.0.0.1 only.
- Automatically maintains the skin after Windows sign-in.
- The draggable polaroid decoration is removed.
- Windows route synchronization is optimized to about 10 ms.

NOTES
- This is an unofficial third-party skin.
- A major future Codex UI update may require a compatibility update.
- Installation and uninstallation restart Codex. Save active work first.
